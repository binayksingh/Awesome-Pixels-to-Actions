# Contributing

Thank you for helping keep this list current.

1. Add the paper to the section of the **highest capability level** it addresses (L1–L6). Papers spanning several levels can say so in the title cell, e.g. `(L3→L6)`.
2. Use one table row in this format, newest first:
   `| Year | **Title** — First Author, Second Author, Third Author et al. | Venue | [arXiv](https://arxiv.org/abs/XXXX.XXXXX) |`
3. Link to the official publication or arXiv abstract page; add a `[Code](...)` link if available.
4. Open a pull request with a one-line description of why the paper fits.
